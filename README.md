# LocalRecord

Privacy-first Android voice recorder with on-device live transcription
(NVIDIA's Parakeet TDT 0.6B v2, run by sherpa-onnx/ONNX Runtime on the CPU),
playback with a word-synced transcript, and sharing to any app (e.g. Drive's
"Save to Drive"). Personal replacement for Pixel Recorder, targeting a
OnePlus 15 (Snapdragon 8 Elite Gen 5).

No audio ever leaves the device unless you share it. Network is used only for
the one-time model download.

## Layout

- `app/` — Kotlin/Compose Android app (thin UI; marshals audio across the
  bridge and renders results)
- `rust-engine/` — Rust crate over sherpa-onnx (prebuilt libs fetched by
  `sherpa-onnx-sys`, nothing vendored here); all transcription logic.
  Kotlin bindings are generated by uniffi.
- `scripts/` — toolchain setup and build scripts

## Build

```bash
scripts/setup-android-sdk.sh   # one-time: SDK + NDK into ~/Android/Sdk
scripts/build-rust.sh          # Rust → app/src/main/jniLibs + uniffi Kotlin bindings
./gradlew assembleDebug        # APK
```

`scripts/env.sh` sets `ANDROID_HOME`/`ANDROID_NDK_HOME`. `build-rust.sh`
sources it automatically.

Live-transcription architecture: sliding-window chunking in
`rust-engine/src/session.rs` — Parakeet has no streaming mode. Inference
re-runs every 4 s of new audio over the uncommitted buffer; segments ending
≥1 s before the buffer end are emitted and trimmed, the rest is re-transcribed
next pass (forced commit at 20 s). Sizes are a first guess pending real device
latency numbers.

## Release (Google Play)

`./gradlew bundleRelease` builds `app/build/outputs/bundle/release/app-release.aab`,
signed with the Play upload key when `~/.gradle/gradle.properties` has:

```properties
localrecord.upload.storeFile=/home/you/keys/localrecord-upload.jks
localrecord.upload.storePassword=...
localrecord.upload.keyAlias=upload
localrecord.upload.keyPassword=...
```

Create the key once (keep it backed up outside the repo; Play App Signing
holds the actual app signing key, so a lost upload key can be reset):

```bash
keytool -genkeypair -v -keystore ~/keys/localrecord-upload.jks \
    -keyalg RSA -keysize 4096 -validity 10000 -alias upload
```

Bump `versionCode` in `app/build.gradle.kts` for every upload. Native libs
must be 16 KB page-aligned (Play requirement); `build-rust.sh` links them so.

## Model

First run: the app offers a one-time download of the models (~690 MB,
SHA-256 verified) from Hugging Face into app-private storage: sherpa-onnx's
int8 export of Parakeet TDT 0.6B v2 (CC-BY-4.0) and a 3D-Speaker CAM++
voiceprint model (Apache-2.0) for speaker labels. Recording works without
them; live transcription starts once they're present.

## Sharing / backup

Each recording has a Share button (list and playback screen) that hands the
`.ogg` (Opus) audio and a WebVTT `.vtt` transcript (speaker labels, per-word start times)
to the system share sheet — pick Drive's "Save to Drive" to back it up.

To bring recordings back (e.g. onto a new phone), tap the import button in
the top bar and pick the `.ogg` (or `.opus`) files, with their `.vtt` transcripts, from
Drive or any other source in the system file picker. Files already in the
app are never overwritten.
